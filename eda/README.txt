EDA MODULE
==========

This module performs exploratory data analysis (EDA) on cleaned primary care electronic health record (EHR) data.

The EDA pipeline is fully independent from the data cleaning pipeline and only consumes cleaned CSV outputs.


PIPELINE OVERVIEW
-----------------

The EDA workflow includes:

1. Construction of patient-level demographic dataset
2. ICD-9 based chronic disease system classification
3. Identification of musculoskeletal (MSK) patients
4. Multimorbidity quantification (non-MSK chronic systems)
5. Estimation of condition duration:
   - First diagnosis date
   - Last diagnosis date
   - Medication-based duration extension
6. Stratified descriptive visualization


REQUIRED INPUT FILES
--------------------

The following cleaned files must exist in:

    data/output/

Required files:

- C4MPatient_clean_1_31.csv
- C4MEncounterDiagnosis_clean_1_31.csv
- C4MMedication_clean_1_31.csv

These files are generated by the data cleaning pipeline.


HOW TO RUN
----------

From the project root directory:

    python eda/main_eda.py

The script will:

- Generate a patient-level analysis dataset
- Produce descriptive visualizations
- Automatically save all outputs


OUTPUTS
-------

All results are saved under:

    eda/results/

Tables:
- analysis_df.csv

Figures (PNG, 300 dpi):
- Comorbid chronic disease distribution
- Multimorbidity count distribution
- Age distribution of MSK patients
- Sex distribution of MSK patients
- Age × Sex distribution
- MSK duration vs Mental duration (by sex)
- MSK type classification distribution
- MSK type distribution stratified by sex


KEY DERIVED VARIABLES
---------------------

- msk_type
    MSK onset pattern classification

- comorbidity_count
    Number of non-MSK chronic systems

- msk_duration_years
    Estimated MSK duration in years

- mental_duration_years
    Estimated mental health condition duration in years

See data_dictionary.md for full variable definitions.
